# YouTube Scraper & Downloader PRO (Termux)

## Install

```bash
pkg install python clang make ffmpeg
git clone https://github.com/rendi-afkar/youtube-downloader-termux.git
cd youtube-downloader-termux
make
./main
```

Butuh license AFKAR (terikat Machine ID perangkat). Machine ID ditampilkan saat aktivasi.
